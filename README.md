# Portafolio — Claudio Alarcón

Portafolio profesional de desarrollo full-stack y aplicaciones web. Incluye proyectos web reales (CMS, sitios dinámicos) y una colección de proyectos gráficos interactivos desarrollados originalmente en Processing y convertidos a p5.js para visualización en el navegador.

## Estructura

```
├── index.html              Página principal del portafolio
├── css/style.css           Estilos profesionales
├── js/main.js              Lógica de navegación, filtros, modales y sketches p5.js
├── projects/               Proyectos convertidos a p5.js (uno por subcarpeta)
├── images/                 Capturas de pantalla y recursos visuales
└── Processing Proyects/    Proyectos originales en Processing (no incluidos en repo)
```

## Tecnologías

- **Frontend:** HTML, CSS, JavaScript, p5.js
- **Backend:** PHP, Node.js (en proyectos)
- **Bases de datos:** MySQL (en proyectos)
- **Herramientas:** Git, Processing

## Proyectos

- **Aplicaciones web:** CMS para comunidades, sitios dinámicos full-stack con PHP y MySQL.
- **Proyectos gráficos:** 19 proyectos que abarcan juegos, simulaciones físicas, visualizaciones 3D, arte generativo, algoritmos de renderizado y machine learning — ejecutables en el navegador gracias a p5.js.
